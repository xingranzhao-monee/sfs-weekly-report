💡 本周启示
1
TikTok Shop 马来西亚将部分买家原因退货双程运费转由卖家承担
平台11月12日公告，12月7日起对三类符合条件的买家原因退货，卖家承担正向及退货运费，并拟分阶段提供由 Igloo 提供、每单最高补偿80林吉特的自愿参加计划；具体费率和资格需在后台确认。对团队的卖家保障业务，这提示应逐项比较保障触发条件、未成功退回等除外责任和按正向订单收费的成本，而不能只看赔付上限。
2
BVNK 已把稳定币余额接到 11 种本地货币的银行付款
BVNK 11月11日宣布通过 Mastercard Move，将企业所持稳定币余额转换为法币并付至收款人本地银行账户，首批覆盖墨西哥、巴西、菲律宾等市场，尚不包括人民币。该能力可供平台付款场景使用，扩至40多种货币则是2027年计划。对中国卖家回款链路，可关注平台余额到当地银行这一环节的服务能力，同时单独核查最终人民币入境、主体资格和合规安排。
3
泰国跨境电商包裹关税调整获批，具体税率与生效日仍待公告
泰国内阁11月10日同意按商品税则对指定跨境电商快递和邮政包裹计征进口税，上限30%；财政部还需发布正式通知，刊登《皇家公报》满15天后才生效。此举可能改变在泰销售商品的含税价格、退货价值与保障赔付测算。团队可让当地伙伴核对税则、实际承担方和订单数据要求，暂不按“全部商品涨至30%”估算成本。
4
Xendit 印尼盾付款延迟显示合作银行故障可传导至出款
Xendit 状态页显示，11月13日晚至14日清晨的合作方系统问题造成部分印尼盾出款、汇款及托管交易处理延迟，平台已标记恢复，公开资料未披露影响笔数。若团队使用当地 PSP 承接卖家或商户资金，类似事件提示需核对目的银行覆盖、故障通知、在途订单对账和备用付款安排；本次不能推断已有 Shopee & Monee 链路受影响。

越南 Mr Pips 案：9Pay 的收款链路与调查状态
截至2026年11月17日18:09（北京时间）核查
越南检方指控 Phó Đức Nam（Mr Pips）等人经营虚假的股票、外汇交易平台，诱导投资者向关联账户入金；庭审涉及通过公司账户和支付中介接收款项。9Pay 被被告、辩护律师和检方提及，调查重点是它在代收代付链路中的具体角色。被提及及列为后续核查对象，不等于已被起诉或认定违法。
关注重点：9Pay 在案中的资金流角色；针对 9Pay 的司法或监管调查阶段；9Pay 的回应和相关商户账户处置。
  1. 10月31日庭审、11月2日报道被告 Phó Đức Nam 称其团伙曾通过 Ngân Lượng、9Pay 等支付网关收取投资者入金；辩护律师请求法庭传唤包括 9Pay 在内的中介代表，以查清资金流。这些是庭审陈述和申请，尚非对 9Pay 的违法认定。越南检察报 →
  2. 11月4日河内检方表示，受本阶段诉讼期限限制，拟在第二阶段继续核查 9Pay、BigPay、ApotaPay、CPay、HTP 等支付中介的活动。该表述意味着仍待调查；报道未显示五家机构已被起诉。VTC News →
  3. 11月6日报道及更新9Pay 向 Fintech News 书面回应称，其风控发现异常交易后冻结并暂停了相关商户账户，主动向有关部门报告，并向调查和监管机构提供资料。账户处置与配合调查均为公司说法，尚无独立处置结论。9Pay回应 →
  4. 11月7日庭审及报道越南法院报披露检方在主案中援引的证据：包括 9Pay 在内的三家支付中介，曾与若干个体经营者及六家公司签订代收代付合同，用于接收被害人款项；调查还发现相关主体与团伙人员账户有资金往来。报道未列出 9Pay 单独经手金额，也未认定其明知参与诈骗。越南法院报 →
  5. 本周报道11月9日移动支付网报道此前庭审与检方第二阶段核查计划，并称“9Pay 至今未就案件公开发表评论”。该报道没有披露新的立案或处罚动作；其“未回应”说法与11月6日披露的9Pay书面回应不一致，应以后者确认的回应内容为准。中文报道 →

截至本期核查，11月9日至15日没有查到针对 9Pay 的新公开起诉、处罚或账户处置结论。11月9日中文报道属于旧庭审进展的本周报道，不能当作本周新调查动作；11月16日主案宣判在统计周之外，也不改变目前可确认的9Pay法律状态。

TikTok Shop 马来西亚调整买家原因退货运费责任，并提供可选补偿计划
11月12日公告 · 12月7日生效 · 马来西亚 · TikTok Shop 卖家中心
TikTok Shop 马来西亚站公告，自12月7日起，对符合条件的“改变主意、商品过大或过小、选错尺码”退货，卖家需承担发给买家的正向运费及退货运费；每位买家每月最多可按上述原因退货3次。正向运费按运费补贴券抵扣后计算，卖家原因退货的原有责任不变。平台同时计划分阶段提供由 Igloo 提供的自愿参加的 Return Shipping Fee Saver：按成功正向订单收取服务费，符合条件的双程运费每单最高补偿80林吉特；自行履约、商品未成功退回及买家自行安排退货等情形不在保障内，卖家须在后台确认自身资格和实际费率。

BVNK 接入 Mastercard Move，推出稳定币余额转本地银行账户付款
11月11日 · 拉美等11个币种市场 · BVNK
BVNK 宣布通过 Mastercard Move，让企业从其平台所持稳定币余额发起付款，由 BVNK 转换为法币，再经本地支付网络进入收款人的国内银行账户；客户可通过 API 或商户后台发起。首批覆盖11种货币，其中拉美包括墨西哥、巴西、阿根廷、哥伦比亚和智利，亚太包括菲律宾和韩国。BVNK 称此能力也可嵌入平台用于向供应商或创作者付款；推卡和电子钱包收款端仍属未来扩展，2027年拓至40多种货币是计划，目前首批不含人民币。

结算试验
英、新、泰央行公布同步外汇结算试验结果
英国央行、金管局和泰国央行公布 Project Meridian FX APAC 结果：在三家央行的测试环境中，协调不同批发结算系统完成付款对付款（PvP）外汇结算，并试验多边净额结算。试验涉及传统实时全额结算与分布式账本环境，表明技术上可行，同时列出法律、运营和监管问题。项目仍是测试，未建立面向商家或 PSP 的正式跨境支付通道；英国央行提出的2028年同步接口也尚非本项目服务上线日期。

泰国内阁批准调整跨境电商包裹进口税，税率依品类最高30%
11月10日 · 泰国 · 泰国政府
泰国内阁11月10日批准调整从境外电商平台购买、经快递或国际邮政进入泰国的商品进口税计收办法。政府称将按商品对应税则征税，上限30%，并与电商平台对接订单数据辅助申报；这不表示所有商品一律按30%征税。财政部仍须起草并公布正式通知，政府公告写明措施将在《皇家公报》刊登后满15天生效。因此截至本期核查时，该调整仍处于已获内阁批准、尚待正式规则与生效日期的阶段。
