跨境金融新闻周报

一

Skill 与周报设计

研究什么、从哪里找、周报怎样呈现

服务对象

中国跨境卖家的金融服务

面向 Shopee 同集团 Monee 的跨境商家金融团队，包括经营主体在海外、仍需人民币回款至中国大陆的卖家。

交付结果

一份可核查的周报

默认统计北京时间最近一个完整自然周（周一至周日），生成带原文链接的 HTML 周报，并列出值得人工复核的候选。周报由人审核、发送。

搜索覆盖

关注内容

以卖家回款、当地 PSP 合作、物流保险和退货退款保障为重点；同时搜索支付与外汇、平台结算、监管与牌照、反洗钱、欺诈风控及重要物流变化。优先关注东南亚、拉美，兼顾中国出口端和有参考价值的其他市场。

来源与规则

先广搜，再核实筛选

从监管和政府原文、企业及平台公告、当地媒体、支付行业媒体、公开公众号等渠道找线索。规则依据团队业务重点及历次周报反馈制定：跨地区、主体、事件和语言搜索，核对原文、日期与事件阶段，再按业务关联和重要性筛选；不设固定篇数。

周报各部分的作用

本周启示：放在周报正文开头，提炼本周对业务影响较直接或较重要的新闻，并给出具体结论或值得留意的点。
持续关注：只跟进团队点名的事件及其指定重点；经确认后手动加入关注清单，再搜索和更新背景、时间线。它排在“本周启示”之后。
当周新闻：按实际事件类型分类，讲清主体、动作、条件和来源，不为凑栏目或篇数收录无关内容。
监管动向：是重点关注项；有相关政策、牌照或执法新闻时独立成栏，并按现行版式排在其他新闻栏目之后。

为什么每天追踪、周一再汇总

团队希望尽可能看见重要负面新闻。此类报道可能因公关处理被删除、修改，或后来变得难以检索；若只在周一集中搜索，就可能错过。每天搜索当天可见的消息，并及时留下日期、来源和简短事实，能提高发现并保留线索的机会。周一再补搜、核实和筛选，形成周报。无论手动还是定时使用，都按这个流程执行。

二

下载与使用

安装、出稿验证、选择运行方式、验收

1

下载提供的 Skill 安装包

下载随指南单独提供的 sfs-weekly-report-skill.zip。自己选定一个本地周报项目，在该项目的对话中让 AI 解压安装包并确认文件位置；不需要使用他人的个人目录。

你选定的周报项目/ ├─ .agents/skills/sfs-weekly-report/ ← Skill 全部文件 ├─ follow-ups.md ← 持续关注清单 ├─ daily/ ← 每日记录 └─ weekly/ ← HTML 周报

若项目已有 follow-ups.md，请先合并关注事项，不要直接覆盖。

2

在该项目的新会话里验证

在同一项目中新建对话，选择 @sfs-weekly-report（Codex 中可用 $sfs-weekly-report），直接让它生成上一个完整周或指定日期范围的 HTML 周报。

可直接发送的验证指令
请生成北京时间最近一个已结束自然周（周一至周日）的跨境金融新闻 HTML 周报，保存到本项目 weekly/，并告诉我文件位置。若我指定了其他日期范围，就按指定范围制作。

这一步用成稿验证安装；正式使用仍需每天追踪、周一汇总。若 Skill 未出现，先检查安装位置和 SKILL.md。

3

选择手动使用，或在桌面版设置定时任务

手动：每天（含周末）在项目对话中调用 Skill，要求“追踪今天的新闻并保存记录”；每周一再要求它根据每日记录和补搜结果制作上一个完整周的周报。

定时：在 ChatGPT 桌面版打开“定时任务”→“新建任务”，依次设置两项任务：

  1. 运行位置选择同一个本地周报项目，让两项任务都能读取 Skill 和项目文件。
  2. 第一项设为每天追踪（含周末），第二项设为每周一汇总。时间由自己选择；按北京时间 Asia/Shanghai 核对下一次运行时间，并确保届时电脑和桌面应用会运行。
  3. 模型建议选 GPT-6 Sol、高推理强度，或自己可用的更高能力模型。填写下方名称和提示词，保存并启用两项任务。
任务一｜名称：跨境金融新闻每日追踪｜频率：每天
在当前本地周报项目调用 $sfs-weekly-report，每日追踪跨境金融新闻及 follow-ups.md 中的持续关注事件。按 Skill 规则核查并记录来源，将本次运行结果保存到本项目 daily/YYYY-MM-DD.jsonl；无新线索也写运行记录。回报实际文件位置和覆盖缺口。不要生成周报或发送邮件。
任务二｜名称：跨境金融周报周一汇总｜频率：每周一
在当前本地周报项目调用 $sfs-weekly-report，制作北京时间最近一个已结束自然周的 HTML 周报。读取本周 daily/ 记录和 follow-ups.md，补搜遗漏时段，重新核实来源，按 Skill 规则筛选；保存到本项目 weekly/，同名文件加版本号。回报实际文件位置、核查截止和缺口。不要发送邮件。
如果无法创建：如“新建任务”没有表单或出现报错，请明确记录“Skill 已可用，任务未创建”，继续手动使用；不要把云端任务当成本地任务。
4

验收后交给团队使用

  • 新会话能调用 Skill，并生成内容完整、质量可用的 HTML 周报
  • 打开周报，检查新闻事实和原文链接是否正确
  • 如选择定时，确认两项任务已启用，并在实际运行后生成对应文件
  • 人工审核、归档后，再发送给团队
